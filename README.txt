# Transcribe Video AI — Ad Wrapper

Ready-to-deploy static website for Netlify or Vercel.

## Files
- index.html
- style.css
- script.js

## Deployment
### Netlify
Drag the project folder/ZIP into Netlify Drop, or connect the repository.

### Vercel
Import the project/repository as a static site. No build command is required.

## Important
The iframe points to:
https://transcribe-video.ai/

The Adsterra/advertising scripts supplied in the original request are already placed in their corresponding slots.

If an ad network later changes a placement key, edit only the relevant script in `index.html`.

## Included placements
- 728x90
- Native responsive
- 160x600
- 300x250
- 468x60
- 160x300
- 320x50 mobile

No framework or build step is required.
